# 报价编辑表格紧凑列宽设计

## 目标

压缩报价编辑页面中内容长度稳定的“预估时段、数量、单价、实际总价”列，把释放出的横向空间分配给“备注 / 其他”，减少备注内容被截断，同时保持整行编辑、拖动排序和删除操作不变。

## 范围

- 仅调整报价编辑器的行程项目网格列宽。
- 新增报价、编辑本人报价、管理员编辑和复制后微调共用同一视图，因此同步生效。
- 不修改报价预览、图片复制、Excel 导出和数据库字段。
- 不修改金额计算、税费计算、拖动排序或增删项目行为。

## 桌面布局

报价项目行继续使用十列 CSS Grid。列宽调整为：

| 列 | 设计宽度 |
| --- | --- |
| 拖动手柄 | 24px |
| 序号 | 25px |
| 预估时段 | 最小 82px |
| 项目名称 | 最小 145px，弹性增长 |
| 单位 | 最小 58px |
| 数量 | 48px 左右 |
| 单价 | 68px 左右 |
| 实际总价 | 78px 左右 |
| 备注 / 其他 | 最小 160px，并优先获得剩余空间 |
| 删除按钮 | 28px |

金额字段仍为单行数字输入框。常见的数量、单价和总价能够完整显示；超出常见长度时允许输入框自身滚动，不扩张整列。

## 窄屏行为

在编辑汇总栏下移的中等宽度下，同样压缩时段和金额列，并保证备注列不小于 130px。现有小屏横向滚动兜底保留，避免在手机宽度强行挤压到无法编辑；桌面宽屏不新增横向滚动。

## 样式约束

- 表头和数据行使用同一个 `.item-grid` 列定义，保持严格对齐。
- 不降低现有输入框字号和高度。
- 项目名称与备注列均允许弹性增长，但备注列获得更高权重。
- 不改变表格外层宽度、右侧费用汇总栏宽度和页面整体布局。

## 验证

1. 增加视图契约测试，断言编辑器包含新的紧凑列宽和备注最小宽度规则。
2. 先运行测试并确认旧样式下失败，再修改 CSS 使其通过。
3. 运行完整 PHP 与 JavaScript 测试。
4. 在本地编辑报价页面检查表头对齐、输入内容可见、备注空间增加、拖动与增删按钮仍正常，并检查控制台错误。
