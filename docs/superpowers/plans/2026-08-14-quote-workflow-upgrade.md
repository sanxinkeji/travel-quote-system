# 报价工作流升级实施计划

## 1. 锁定复制和权限行为

- 在报价功能测试中先加入：打开复制编辑不写库、保存才新增、来源不变、所有者正确、非所有者禁止更新删除、管理员可管理全部。
- 增加复制编辑 GET 与复制保存 POST 路由。
- 将现有立即落库复制改为临时表单数据，并在事务中保存新报价和明细。
- 保留 `source_quote_id`，新记录状态设为历史报价。

## 2. 增加行程拖动排序

- 加入本地 SortableJS 资源和拖动手柄。
- DAY 容器使用共享拖动组，其他项使用独立组。
- 动态新增 DAY 后初始化拖动；结束时更新字段名、顺序和金额。
- 增加后端结构校验，保证最多一个其他项且位于最后，税费只能位于其他项。
- 加入视图契约和请求验证测试。

## 3. 重建样式化 Excel 导出

- 用支持样式的 XLSX 浏览器构建替换当前只导出内容的实现。
- 明确生成标题、联系信息、提示、明细、小计和汇总行，避免依赖 HTML 转换推断格式。
- 设置合并、字体、填充、边框、对齐、换行、行高、列宽和金额数字格式。
- 加入工作簿结构测试，覆盖主要合并区域、样式和数值类型。

## 4. 整理操作入口和字体

- 删除标题链接与查看图标的重复入口。
- 将详情编辑按钮改名为“编辑原报价”。
- 保留管理员历史列表删除入口和预览三种导出能力。
- 放大历史列表、编辑器、报价单字号与必要内边距。

## 5. 验证和发布

- 运行 PHP 单元与功能测试。
- 运行前端脚本测试或静态契约测试。
- 在本地浏览器验证拖动、复制保存、权限提示和 Excel 下载。
- 检查 1440px、1280px 和 390px 布局。
- 构建发布 ZIP，备份后部署到宝塔站点，执行迁移和缓存刷新，再做线上冒烟测试。
